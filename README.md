# CCG Berserk

Welcome to the **CCG Berserk** project.

## Project Information

- **Unity Version**: 2022.3.14f1
- **Development Version**: 3.7.0

## How to run

- Open the project and wait about 10 minutes for the assets to compile for the first time.
- Open the Scenes / **Init.scene**
- Setup the Addressables Groups / Play Mode Script / **Use Asset Database**
- Press the Play button.
- Select the **Dev** environment in the selection window that appears.

## How to debug mode
- Use the console on the **~** button on your keyboard or the UI button on the left side of the screen labeled **Cons**.
- Write the command **help** or **?** to see all commands available on the active scene. The game and the lobby have a different set of commands.
